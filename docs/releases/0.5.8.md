# 随想画卷 0.5.8

新增与[角色日程 0.3.1](https://github.com/iownmmiku/astrbot_plugin_persona_schedule)的可选联动。在日程插件中打开“随想画卷联动”后，主动消息及早安参考角色当前活动，忙碌时直接取消该次机会，半忙时保持简短或自行跳过。

- 联动默认关闭，遵守日程总开关与对话白名单；未安装、停用或旧版没有接口时沿用原主动策略。
- 决策后和生图后复核日程摘要、当前 AstrBot 人格与会话。忙碌、身份或活动改变、开关中途改变及读取异常都会取消旧内容，不进入待回队列，也不在空闲后补发。已生成的取消照片保留记录且不能补发。
- AstrBot 4.28 使用官方人格解析器匹配会话覆盖、默认人格和平台规则，发送前身份核对不会修改视觉会话。
- 更新日志、使用说明、页面版本与安装包已同步。

335 项离线回归通过，其中新增 27 项联动回归；JavaScript 语法、版本及 ZIP 安装结构检查通过。测试使用临时数据及模拟接口，真实 AstrBot、聊天平台及绘图服务尚未联调。已提交的绘图可能继续计费，已交给平台的消息不能撤回；模型不保证完全遵守活动资料。

升级时安装附件 `astrbot_plugin_persona_canvas.zip` 并重载插件；同时安装或升级角色日程至 0.3.1，并按需打开联动。原设置与数据保留。
